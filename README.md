# Hitesh Arun Kanojiya — Personal Portfolio

A responsive personal portfolio built with **HTML, CSS, and JavaScript**.

## Project files

- `index.html` — page structure and portfolio content
- `style.css` — dark theme, layouts, and responsive styling
- `script.js` — mobile navigation, active-section highlighting, and dynamic year

## Before submitting

1. Open `index.html` in your browser and review every section.
2. Replace `your.email@example.com` with your real email address in both the email link and visible text.
3. Replace the GitHub profile link with your own GitHub profile URL.
4. Update the project cards with projects you have actually completed. Add links to their repositories if available.
5. Confirm your university/course wording and update it if needed.
6. If you want to use a real profile picture later, replace the CSS avatar placeholder in the hero section with an image you own.

## Run locally

No build tools are required. Open `index.html` directly in a browser. For local development, you can also use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com/) and create a **new public repository** named `hitesh-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder. Keep `index.html` at the root.
3. Open the repository's **Settings**.
4. Select **Pages** from the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to finish publishing. Your site URL will usually be:
   `https://hiteshkanojiya511-ship-it.github.io/hitesh-portfolio/`
8. Open the live URL on both a phone and a computer. Test every navigation link and the email link.
